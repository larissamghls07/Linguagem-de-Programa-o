## 📌 Sobre a Disciplina
A disciplina é uma **continuação direta de Algoritmos e Python**, avançando no desenvolvimento de software e estruturação de código. O foco principal atual está no estudo e construção de **Interfaces Gráficas (GUI)** utilizando as bibliotecas:
- **Tkinter**
- **PySimpleGUI**
